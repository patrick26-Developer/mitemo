# Mémoires

Notre façon de travailler et de raisonner sur Mitemo, tirée du travail réel (PR #99, #100, audit UX des formulaires). À lire avant de reprendre une tâche. [`AGENTS.md`](../AGENTS.md) reste la règle ; ces fichiers expliquent **comment** on l'applique au quotidien.

| Dossier                          | Contenu                                                    |
| -------------------------------- | ---------------------------------------------------------- |
| [`methode/`](methode/)           | déroulé d'une tâche, TDD, vérifications, commits, branches |
| [`raisonnement/`](raisonnement/) | comment on tranche : quoi décider seul, quoi demander      |
| [`ux/`](ux/)                     | règles d'interface imposées sur le mobile                  |
| [`mobile/`](mobile/)             | briques partagées à réutiliser et pièges de tests connus   |

Une mémoire = un sujet. Quand une règle change, on met à jour le fichier existant au lieu d'en créer un nouveau.
